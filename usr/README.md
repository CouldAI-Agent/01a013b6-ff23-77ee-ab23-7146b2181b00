# MoviePlay Hub

A complete, professional, mobile-first Telegram Mini App built with Flutter.

## Features
- **Simple Games**: Daily challenges, tap/click games, quiz, leaderboard.
- **Movies & Series**: Discover trending movies, top releases, genres, and cast details.
- **Referral System**: Unique referral links, rewards, and leaderboards.
- **Monetag Integration Ready**: Prepared architecture for Monetag ad placements.
- **Telegram Mini App**: Deeply integrated with Telegram WebApp SDK.

## Tech Stack
- **Frontend**: Flutter (Mobile-first Web application)
- **Backend**: Node.js/PostgreSQL (API mock ready)
- **Integration**: Telegram Web App

## Setup & Run
1. Install Flutter dependencies:
   ```bash
   flutter pub get
   ```
2. Run the application (Web preview for Telegram):
   ```bash
   flutter run -d web-server --web-port 8080
   ```

## Deployment Notes
- Build for web: `flutter build web --web-renderer html`
- Host on a static server (Vercel, Firebase, GitHub Pages).
- Connect the URL to a Telegram Bot as a Mini App or Web App.
